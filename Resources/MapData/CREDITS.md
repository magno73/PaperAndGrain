# Map data

`world.mapdata` holds land, large lakes, country borders and populated places for map pages. It is
generated by `scripts/make-map-data.py` from **Natural Earth** (<https://www.naturalearthdata.com>),
release `v5.1.2` of <https://github.com/nvkelso/natural-earth-vector>:

| File | Scale | Kept |
|---|---|---|
| `ne_50m_land.geojson` | 1:50m | land outlines |
| `ne_50m_lakes.geojson` | 1:50m | large lakes |
| `ne_50m_admin_0_boundary_lines_land.geojson` | 1:50m | country borders; lines the data does not mark as agreed boundaries are drawn dashed |
| `ne_10m_populated_places.geojson` | 1:10m | name, Italian and English names, position and population |

Natural Earth is in the **public domain**: no permission or credit is needed. Made with Natural Earth.
Its default view of disputed areas follows who controls the territory
(<https://www.naturalearthdata.com/about/disputed-boundaries-policy/>); the app uses that view and
does not print country names.

The file is not generated yet: the script downloads from GitHub and is run only with the author's
consent. Unit tests use `Tests/Fixtures/test-map.mapdata`, synthetic shapes written by
`scripts/make-map-data.py --fixture`, not geography.
